# Рабочие артефакты фазы Ф0+Ф1

Здесь лежит то, что осталось от процесса, а не от результата: журнал решений и отчёты
исполнителей и ревьюеров по каждой из восьми задач плюс волне исправлений.

Зачем это в репозитории. Почти все измерения фазы — размеры групп покрытия, доли выживших
картинок, масштабы найденных дефектов, способы проверки — сделаны один раз и живут только здесь.
Итоговый документ фазы (`../ф0-ф1-отчёт.md`) содержит выводы; эти файлы содержат то, **как** к ним
пришли, включая ошибки и их исправления.

- `журнал-решений.md` — хронология с решениями, отложенными находками и обоснованием каждого
  отступления от плана. Читать первым.
- `review-final-report.md` — итоговое ревью всей ветки: восемь дефектов, из-за которых потребовалась
  волна исправлений.
- `review-fixwave-verdict.md` — перепроверка волны с измерениями на всём корпусе.
- `fixwave-report.md`, `task-N-report.md` — отчёты по работам.

Все команды в отчётах писались воспроизводимыми; там, где цифра оказывалась неверной, это
исправлено прямо в тексте с пометкой.
