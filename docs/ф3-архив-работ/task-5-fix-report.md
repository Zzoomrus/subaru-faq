1. **R1 после R3 — не буквальная реализация задания.** Исходная формулировка R1
   («выстави mtime в прошлую дату, утверждай именно её») требует, чтобы `build`
   ПРОДОЛЖАЛ уметь брать дату из mtime — а R3 требует убрать эту возможность
   целиком. Я сделал так: сначала починил тест буквально (коммит `7b23d641`,
   доказал мутацией), затем в коммите R3 (`195c60a4`) убрал саму mtime-ветку и
   заменил тест на эквивалентный по силе — «никакой неявный источник (ни mtime, ни
   `date.today()`) не просачивается», что и есть подлинная защита, которую искал
   R1. Если для тебя важна буквальная формулировка теста — дай знать, но код,
   который бы прошёл ТОЧНО такой тест, противоречил бы R3.
2. **Порядок правки R3 менялся на ходу.** Твоё сообщение про обязательность

   Упоминаю на случай, если что-то из этой правки выглядит не так, как ты ожидал.
