# Разведка automn.ru перед скачиванием — отчёт

**Дата разведки:** 2026-08-23. **Источник:** `http://automn.ru/subaru-legacy-outback/` (Legacy/Outback) и
`http://automn.ru/subaru-forester/` (Forester) — руководства по обслуживанию и ремонту, разбитые по
главам. Ссылки на сайт лежат в архиве мёртвого форума; почти все соседние ссылки не выжили, этот —
один из двух живых.

**Метод.** Только оглавления и выборочные страницы (~45 запросов всего), без массового скачивания.
Задержка между запросами 2.5–3 с, обычный UA, однопоточно. Черновые файлы — `/tmp/automn-recon/`,
в проект/вики ничего не писалось.

## 1. Объём

| Раздел | Уникальных страниц с содержанием |
|---|---|
| Legacy/Outback | **498** |

Посчитано обходом всех 14 глав каждого раздела и всех вложенных под-оглавлений (там, где они есть),
с дедупом по URL на уровне всего сайта (страница, встречающаяся в нескольких меню, посчитана один раз).

## 2. Структура

Иерархия трёхуровневая, но не единообразная: **глава → (иногда) подглава → страница**. Часть глав —
плоские (все процедуры прямо в главе), часть разбита на подглавы, которые нужно обходить отдельным
запросом, чтобы найти списки страниц.

**Практический вывод для скачивания:** нельзя один раз собрать список страниц с оглавления раздела —
нужен обход в глубину (глава → если есть autocategory-подссылка с `.m_id-` — зайти и туда), иначе
пропустишь главы 2, 4, 5, 6, 9/10, 12, 14.

| Образец | Глава | Тип | Вес HTML | Видимый текст | Таблиц | Картинок в контенте |

Наблюдения:
- **Справочные страницы («Спецификации»)** — это чистые таблицы: моменты затяжки, зазоры, объёмы
  жидкостей, давления. Именно то, что нужнее всего в базе знаний, и картинок там почти нет — самое
  дешёвое и самое ценное содержимое сайта.
- **Процедурные страницы** густо иллюстрированы: 10–17 картинок на страницу, план ремонта пронумерован
  по шагам со ссылками на конкретные детали на схеме («затяните болты (7)–(10)», «сальник (А)»),
  внутри встречаются конкретные моменты затяжки в Нм и номера деталей/спецключей (ST 499497000,
  герметик Three Bond 1280B). Без картинок эти страницы почти бесполезны — текст ссылается на цифры на
  схеме.
- Картинки **не встроены** (не base64) — отдельные JPEG-файлы на поддомене `s7.automn.ru`
  (`http://s7.automn.ru/subaru-legacy-outback/.../14-1.jpg` и т.п.), проверенные образцы весят
  15–18 КБ каждый. Плюс горстка общих иконок сайта (логотип, значки «внимание»/«предупреждение») —
  они переиспользуются на каждой странице, их достаточно скачать один раз.
- HTML на 60–70% состоит из шаблонного шума: дерево навигации по всем маркам/моделям сайта на каждой
  странице, хлебные крошки, футер. Реальный текст статьи — обычно 8 000–24 000 символов из
  30 000–90 000 байт HTML.

## 4. Технические условия скачивания

- **robots.txt** (`http://automn.ru/robots.txt`): `User-agent: * / Disallow: (пусто) / Host: automn.ru`
  — полностью разрешён обход, ограничений по разделам или частоте нет.
- **Отзывчивость:** ~45 запросов подряд с паузой 2.5–3 с, все ответы `200 OK`, без единого таймаута,
  429 или признаков антибот-защиты. Время ответа HTML-страниц 0.4–3.5 с (в среднем ~0.8 с), картинок —
  сопоставимо. Сервер — nginx/1.18 на Ubuntu, отдаёт `_csrf`-куку (CMS на PHP/Yii), но для чтения кука
  не требуется.
- **Оценка веса:**
  - HTML всех 775 страниц: по образцам среднее ~55 КБ/стр. → **≈ 41 МБ**.
  - Картинки: у процедурных страниц ~10–17 шт./стр., у справочных — 0; по грубой прикидке (с учётом
    переиспользования общих иконок и части схем между соседними страницами) — **порядка 3000–4000
    уникальных JPEG** по 15–18 КБ → **≈ 50–60 МБ**.
  - **Итого полное зеркало (HTML + картинки): ≈ 90–100 МБ.**
- **Оценка времени** (однопоточно, пауза 2.5 с между запросами, как требует вежливость):
  - Только HTML (775 запросов): **≈ 30–35 минут**.
  - Полное зеркало с картинками (~4000–4800 запросов всего): **≈ 3–3.5 часа**.
  - Можно смело гонять фоном, антибот-риска не увидено ни разу за разведку.

## 5. Риск: насколько сайт «умирающий»

- Картинки отдаются с заголовком `Last-Modified: апрель 2008` — сам контент (это оцифровка бумажного
  руководства по Legacy/Outback ~2003–2009 годов) не менялся 18 лет. Сайт не живой в смысле «обновляется»,
  это заморозка одной и той же версии руководства.
- При этом сайт **не заброшен технически**: отвечает быстро и стабильно, robots.txt открыт, HTML
  генерируется динамически (не статический дамп, CMS жива и держит сессии/CSRF).
- Wayback Machine показывает снапшот от **2025-09-11** — сайт был доступен и структурно таким же
  ещё год назад.
- Юридическая подпись в футере («по истечении 50 лет с момента смерти автора произведение переходит
  в общественное достояние») — самодельная и спорная, но она годами не менялась, что говорит о
  «поставили и забыли» режиме поддержки: один человек/небольшая команда, без активного развития,
  но и без явных признаков скорого закрытия (не висит объявление о продаже домена, не редиректит
  на парковочную страницу, отвечает не с ошибками).
- Контекст задачи (это «один из двух выживших» линков в архиве мёртвого форума) — единственный
  реальный сигнал риска: домены такого типа исчезают внезапно (истечение регистрации, смерть
  единственного автора, смена хостинга), без предупреждения. Whois-проверку срока регистрации домена
  разведка не делала (вне периметра задачи, при желании — отдельный дешёвый запрос).

**Вывод по риску:** не «горит», но и гарантий нет — типичный «тлеющий» персональный сайт: жив, стабилен,
отвечает быстро, но одному человеку, без бэкапов на твоей стороне. Торопиться в смысле «прямо сегодня»
не обязательно, но и откладывать на месяцы — рискованно задаром, раз скачивание дёшево.

## 6. Рекомендация

- **Забирать оба раздела целиком** (Legacy/Outback 498 стр. + Forester 277 стр. = 775 страниц,
  ~90–100 МБ) — объём скромный, резать главы ради экономии смысла нет: самое ценное (таблицы
  спецификаций) как раз в «маленьких» главах, а самые большие главы (11, 14) — это не раздутость,
  а полнота (тормозная система и бортовая электрика реально большие разделы руководства).
- **Обязательно с картинками.** Процедурные страницы без схем нечитаемы (ссылки на пронумерованные
  детали на рисунке). Экономить на этом — испортить именно те страницы, ради которых стоило качать.
- **Не трогать остальной automn.ru** — общий каталог марок/моделей (`autocat-*`, `auto_review.html`
  и т.п.) не часть руководства, это чужая навигация сайта, не нужна.
- **План скачивания:** обход в глубину по дереву глава→подглава→страница (см. раздел 2), однопоточно,
  пауза 2.5–3 с, обычный UA — уложится в ~3–3.5 часа фоном, антибот-риска не видно. Отдельно
  закешировать общие иконки сайта один раз, не тянуть их с каждой страницы.
