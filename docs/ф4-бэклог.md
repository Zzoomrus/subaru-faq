# Долги и находки Ф3, которые обязаны попасть в план Ф4

Собрано из журнала решений и отчёта пилота. Каждый пункт с причиной, чтобы при планировании не
поднимать переписку.

## Работы

1. **Дособрать разделы 17 и 19** (68 тем, ~528 постов, ~1240 фактов, 30-40 статей) — рекомендация
   отчёта Ф3 §5: проверить конвейер на объёме до решения по ядру.
2. **Добор 248 недостающих картинок FAQ и блогов** — нужна сеть и VPS (троттлинг архива
   ~1,9 стр/мин). Плюс 14 из 15 картинок комментариев блогов: адреса уже в базе.
3. **Вынести картинки из истории git** — до добора, иначе объём истории растёт необратимо.
   `.git` уже 258 МиБ против 277 МиБ рабочей вики.
4. **Прогон `--retry no_snapshot|empty`** — 5106 обращений к индексу, осознанная сетевая операция,
   отдельным прогоном.
5. **Общий каталог вложений сведён** (Ф3, задача 2) — остаток 108 копий по содержимому исчез;
   пункт закрыт, оставлен для истории.
6. **Сверка словесных утверждений с цитатой** — слепая зона проверяльщика (отчёт Ф3 §4). Отдельная
   задача масштаба фазы, решать отдельно от объёма.

## Что знать до первой статьи Ф4

- **Правила прохода 2**, выведенные на пилоте и снявшие весь класс ложных срабатываний: числа и
  единицы в форме источника без перевода; контекст только из своей цитаты; маркер в строке
  таблицы; не усиливать уверенность. Их надо давать автору **сразу**, с примерами провалов — три
  автора пилота на них попались до того, как получили правила, и ни разу после.
- **Проверяльщик видит только утверждения с числами.** Остальное держится на инструкции.
- **Заголовок статьи проверяется на коллизию при сборке** — уточнять по существу
  («Диагностика датчика детонации»), а не приписывать суффикс.
- **39 % постов форума не дают ни одного факта** — это норма плотности, а не плохая работа
  сборщика.
- **Брак первого прохода нулевой**, врёт второй: 3 расхождения на 228 фактов (1,3 %).
