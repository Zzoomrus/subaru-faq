# Новые тарифы ОСАГО с 12.04.2015

##### Пост 394207

*Elena · 15.05.2015 16:03:40 · #1*

С 1 апреля 2015 года, по решению Центрального банка России, были повышены базовые тарифные ставки по ОСАГО.

- Для грузовых автомобилей с разрешенной максимальной массой более 16-ти тонн, базовая тарифная ставка увеличилась примерно на 32%.

- Для других категорий транспортных средств, базовые тарифные ставки увеличились в среднем на 40%.

 Для расчета стоимости Вашего полиса ОСАГО, воспользуйтесь [калькулятором расчета стоимости ОСАГО](http://gk-auto.ru/kalkulyator-rascheta-stoimosti-osago) на сайте страхового брокера ООО "Авто Иншуранс".

 Здесь же, Вы сможете посмотреть новые базовые тарифы и из чего складывается [стоимость полиса ОСАГО](http://gk-auto.ru/novyie-tarifyi-osago.html).
