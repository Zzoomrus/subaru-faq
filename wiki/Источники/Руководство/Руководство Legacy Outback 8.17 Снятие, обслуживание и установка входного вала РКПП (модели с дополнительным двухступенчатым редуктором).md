# 8.17 Снятие, обслуживание и установка входного вала РКПП (модели с дополнительным двухступенчатым редуктором)

## Текст

Снятие, обслуживание и установка входного вала РКПП (модели с
  дополнительным двухступенчатым редуктором)

СНЯТИЕ

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| 1. Снимите сборку РКПП (см. Раздел Снятие и установка трансмиссионной сборки). 2. Снимите раздаточную коробку с корпусом удлинения (см. Раздел Снятие, обслуживание и установка раздаточной коробки и удлинения трансмиссии). 3. Снимите картер трансмиссии (см. Раздел Снятие, установка и проверка состояния картера трансмиссионной сборки). 4. Снимите сборку вала ведущей шестерни (см. Раздел Снятие, обслуживание и установка сборки вала ведущей шестерни главной передачи привода передних колес). 5. Извлеките входной вал в сборе с первичным. |

РАЗБОРКА

 ПОРЯДОК ВЫПОЛНЕНИЯ

![[assets/fd77c978d61385a1.jpg]]

1. Снимите уплотнительное кольцо
                    и регулировочную шайбу с держателя входного вала.

|  | Улотнительное кольцо подлежит замене в обязательном порядке. Количество регулировочных шайб может изменяться от 0 до 2. |
| --- | --- |

                  A — Держатель входного вала

                  B — Уплотнительное кольцо

                  C — Регулировочная шайба держателя

2. С целью предотвращения повреждения сальника обмотайте шлицы
              первичного вала изоляционной лентой.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/2-jpg_/pdfs/chap06/pict/190.jpg)

3. При помощи щипцов извлеките
                    внутреннее пружинное стопорное кольцо.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/2-jpg_/pdfs/chap06/pict/191.jpg)

4. Легкими постукиваниями молотка
                    с мягким бойком по торцевой части входного вала, выстучите
                    последний из своего держателя.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/2-jpg_/pdfs/chap06/pict/192.jpg)

5. Снимите наружное пружинное
                    стопорное кольцо. Затем снимите маслоотжимную пластину и штифт.

                    A — Стопорное кольцо

                    B — Маслоотжимная пластина

 6. Снимите установленное под маслоотжимной пластиной стопорное
              кольцо.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/2-jpg_/pdfs/chap06/pict/194.jpg)

7. При помощи пресса и держателя
                    ST 498077000 снимите шариковый подшипник, - предварительно
                    извлеките внутреннее стопорное кольцо.

8. Извлеките из держателя входного вала сальник.

ПРОВЕРКА

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| См. Раздел Снятие, обслуживание, установка и регулировка первичного вала РКПП. |

СБОРКА

 ПОРЯДОК ВЫПОЛНЕНИЯ

1. Сборка производится в порядке, обратном порядку
              демонтажа компонентов, - посадка вала в держатель производится вручную.
              Не забудьте заменить уплотнительное кольцо держателя.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/2-jpg_/pdfs/chap06/pict/195.jpg)

2. Для установки шарикового
                    подшипника воспользуйтесь специальными приспособлениями ST1
                    899580100 и ST2 399513600, - предварительно установите между
                    шестерней входного вала и подшипником пружинное стопорное
                    кольцо.

3. Установка сальника производится при помощи оправки ST 398507703,
              - предварительно смажьте рабочие кромки сальника.

              4. Перед установкой пружинных стопорных кольца на держатель входного
              вала произведите подбор кольца по приведенной ниже таблице таким
              образом, чтобы зазор между ним и шариковым подшипником не выходил
              за пределы диапазона 0 ÷ 0.12 мм.

Перечень выпускаемых стопорных колец

| № детали | Толщина, мм |
| --- | --- |
| 80516820 | 1.84 |
| 80516830 | 1.92 |
| 80516840 | 2.00 |
| 80502850 | 2.48 |
| 80502860 | 2.56 |
| 80502870 | 2.64 |

УСТАНОВКА

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| 1. Посадите игольчатый подшипник и сальник на переднюю цапфу первичного вала. 2. Подсоедините входной вал к первичному. 3. Посадите наружную обойму игольчатого подшипника приемным отверстием на штифт картера трансмиссии. 4. Дальнейшая установка производится в порядке, обратном порядку демонтажа компонентов. |
