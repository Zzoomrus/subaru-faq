# 14.29 Снятие, проверка состояния и установка компонентов единого замка

## Текст

Снятие, проверка состояния и установка компонентов единого замка

|  | Рассматриваемые в настоящем Руководстве модели автомобилей оборудованы системой дополнительной безопасности (SRS). Прежде чем приступать к выполнению каких-либо работ вблизи блока подушки безопасности, рулевой колонки или приборной панели, отключайте SRS во избежание получения травм при случайном ее срабатывании (см. Раздел Система дополнительной безопасности (SRS) - устройство и принцип функционирования). Электропроводку цепи SRS легко отличить по желтому цвету изоляции. |
| --- | --- |

Модуль управления единого замка

Снятие и установка

 ПОРЯДОК ВЫПОЛНЕНИЯ

 1. Отсоедините отрицательный провод от батареи.

              2. Снимите вещевой ящик (см. Главу
Кузов).

![[assets/a5d642c5a79603d6.jpg]]

3. Отдайте крепежную гайку
                    и, отсоединив электропроводку, снимите модуль управления единого
                    замка в комплекте с модулем управления темпостата.

4. Установка производится в обратном порядке.

Элемент питания трансмиттера пульта ДУ единого замка

|  | Во избежание выхода из строя печатной платы трансмиттера предварительно произведите самозаземление, взявшись рукой за металлический элемент какой-либо постройки! |
| --- | --- |

Снятие

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| Выверните крепежный винт, снимите крышку и извлеките из головки ключа зажигания элемент питания трансмиттера пульта ДУ. |

Проверка

 ПОРЯДОК ВЫПОЛНЕНИЯ

![[assets/974153a623710f17.jpg]]

1. Измерьте напряжение между
                    полюсами снятого элемента питания.

|  | Через 3 секунды измерения напряжение элемента падает более чем до 1.8 В. |
| --- | --- |

|  | Во избежание разрядки элемента питания продолжительность измерения должна составлять не более 5 секунд! |
| --- | --- |

2. Если результат измерения составляет менее 2 В, замените элемент
              питания.

|  | Через 3 секунды измерения напряжение элемента падает более чем до 1.8 В. |
| --- | --- |

Регистрация нового трансмиттера

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| На одном автомобиле может быть зарегистрировано одновременно не более трех трансмиттеров. 1. Снимите боковую накладку порога водительской двери (см. Главу Кузов) иллюстрации соедините контактную пару регистрационного разъема в нижней части передней стойки. 2. Разблокируйте дверной замок. 3. Дважды нажмите на кнопку трансмиттера, дверной замок должен автоматически заблокироваться, затем вновь разблокироваться, что подтверждает успешное завершение регистрации первого трансмиттера. 4. В случае необходимости повторите процедуру для регистрации второго/третьего трансмиттера. 5. Закончив процедуру регистрации, рассоедините контактную пару регистрационного разъема и удостоверьтесь в исправности функционирования вновь зарегистрированных трансмиттеров. 6. Установите на место снимавшиеся с целью обеспечения доступа компоненты. |

Активаторы замков передних дверей

Снятие и установка

 ПОРЯДОК ВЫПОЛНЕНИЯ

 1. Снимите сборку защелки замка (см. Раздел
Снятие, установка и проверка компонентов замковых сборок).

![[assets/96376a87e35886cb.jpg]]

2. Выверните крепежные болты
                    и снимите активатор.

3. Установка производится в обратном порядке. Удостоверьтесь в
              исправности функционирования активатора.

Проверка

 ПОРЯДОК ВЫПОЛНЕНИЯ

 1. Отсоедините от активатора электропроводку.

![[assets/cff5984a9b788a7a.jpg]]

2. Подключите батарею положительным
                    полюсом к клемме № 2 контактного разъема, а отрицательным
                    - к клемме № 4, - активатор должен перейти в заблокированное
                    состояние.

3. При смене полярности подключения батареи активатор должен разблокироваться.

              4. Неисправный активатор подлежит замене.
