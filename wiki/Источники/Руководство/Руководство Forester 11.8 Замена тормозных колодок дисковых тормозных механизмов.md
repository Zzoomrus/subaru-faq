# 11.8 Замена тормозных колодок дисковых тормозных механизмов

## Текст

Замена тормозных колодок дисковых тормозных механизмов

|  | Замена тормозных колодок должна производиться одновременно на обоих передних/задних тормозных механизмах. Помните, что вырабатываемая в процессе работы тормозных механизмов пыль может содержать чрезвычайно вредный для здоровья человека асбест. Ни в коем случае не сдувайте пыль сжатым воздухом и не вдыхайте ее, - при обслуживании механизмов надевайте защитную маску или респиратор. Ни в коем случае не используйте для протирки компонентов тормозной системы бензин или растворители на нефтяной основе, - применяйте только фирменные чистящие средства или метиловый спирт! |
| --- | --- |

Тормозные механизмы передних колес

Снятие

|  | Не отсоединяйте от суппорта гидравлический шланг и не выжимайте педаль ножного тормоза после снятия суппорта! |
| --- | --- |

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| 1. Ослабьте гайки крепления передних колес. Поддомкратьте передок автомобиля и установите его на подпорки, подоприте противооткатными башмаками задние колеса. Снимите передние колеса. 2. Откачайте из резервуара ГТЦ приблизительно 2/3 тормозной жидкости, - при отжимании поршней уровень жидкость может начать вытесняться из резервуара. Заведите сливную емкость под сборку тормозного механизма и обработайте поверхность последнего специальным очистителем. 3. Выверните нижний направляющий болт суппорта. 4. Развернув суппорт, снимите его с тормозного диска и подвяжите проволокой в поднятом положении. 5. Извлеките из анкерной скобы тормозного механизма колодки, фиксаторы и регулировочные шайбы. 6. Оцените степень износа фрикционных накладок тормозных колодок. Если колодки изношены ниже допустимого предела (см. Спецификации) приготовьте сменный комплект. |

|  | Замена тормозных колодок производится одновременно на обоих тормозных механизмах одной оси автомобиля! |

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| 1. Отожмите поршень внутрь сборки колесных цилиндров, - проследите, чтобы тормозная жидкость не начала перетекать через край резервуара ГТЦ, в случае необходимости откачайте из резервуара избыток жидкости. 2. Смажьте антивизговым составом сопрягаемые поверхности колодок, их фиксаторов и внутренних регулировочных прокладок. 3. Установите антивизговые регулировочные прокладки обеих колодок. Заправьте в анкерную скобу тормозного механизма пружинные фиксаторы, затем установите колодки. 4. Опустите суппорт и добейтесь попадания выступов колодок в приемные пазы поршней. 5. Установите нижний направляющий палец. 6. Несколько раз выжмите педаль ножного тормоза для усадки компонентов механизма. 7. Прокачайте соответствующий гидравлический контур (см. Раздел Прокачка тормозной системы). |
