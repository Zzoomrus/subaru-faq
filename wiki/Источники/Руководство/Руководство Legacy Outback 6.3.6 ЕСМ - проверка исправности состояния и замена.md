# 6.3.6 ЕСМ - проверка исправности состояния и замена

## Текст

ЕСМ - проверка исправности состояния и замена

ПРОВЕРКА

| ПОРЯДОК ВЫПОЛНЕНИЯ |
| --- |
| 1. На всех моделях ЕСМ крепится справа под панелью приборов. 2. При работающем двигателе кончиками пальцев резко постучите по стенке модуля, - если ЕСМ неисправен, постукивание может привести к нарушению стабильности оборотов двигателя, одновременно на дисплее подключенного к системе бортовой диагностики (OBD) сканера высветятся текущие сведения о характеристиках работы двигателя. 3. Прежде чем приступать к замене модуля проверьте исправность состояния и надежность крепления контактных соединений электропроводки его цепи. Каждый контактный разъем окрашен в индивидуальный цвет, что исключает вероятность неправильного подсоединения электропроводки при установке ЕСМ. При отсутствии очевидных признаков нарушения исправности функционирования модуля управления автомобиль следует отогнать на станцию техобслуживания для проведения более подробной диагностики модуля. |

ЗАМЕНА

 ПОРЯДОК ВЫПОЛНЕНИЯ

|  | Рассматриваемые в настоящем Руководстве модели автомобилей оборудованы системой дополнительной безопасности (SRS). Прежде чем приступать к выполнению каких-либо работ вблизи блока подушки безопасности, рулевой колонки или приборной панели, отключайте SRS во избежание получения травм при случайном ее срабатывании. Электропроводку цепи SRS легко отличить по желтому цвету изоляции! |
| --- | --- |

|  | Во избежание повреждения ЕСМ электростатическим разрядом, старайтесь не прикасаться к контактным клеммам модуля. По возможности производите самозаземление. |

                    правой передней двери.

3. Отпустите фиксаторы и снимите
                    мат коврового покрытия правого ножного колодца.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/1-jpg_/pdfs/chap04/pict/22-7.jpg)

4. Снимите защитную крышку
                    ECM.

5. Отдайте гайки крепления
                    ECM к опорному кронштейну.

(изображение не сохранилось: http://s7.automn.ru/subaru-legacy-outback/1-jpg_/pdfs/chap04/pict/22-9.jpg)

6. Высвободите из кронштейна
                    хомут жгута электропроводки, рассоедините контактный разъем
                    и снимите ECM.

            7. Установка производится в обратном порядке.

|  | Проследите, чтобы сменный модуль соответствовал по типу вышедшему из строя, - установка ECM иной спецификации может явиться причиной повреждения компонентов системы впрыска топлива! |
