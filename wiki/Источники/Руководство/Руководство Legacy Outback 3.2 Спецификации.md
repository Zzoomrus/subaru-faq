Топливо

 Тип

 Двигательное масло

Тип

Универсальное моторное масло для бензиновых двигателей класса SH или SJ
      по классификации API, с маркировкой «ENERGY CONSERVING II» (Энергосберегающее
      II), - если невозможно достать SH или SJ, допускается использование масла
      класса SG, либо G4 или G5 по классификации CCMC, либо A1, A2, A3 по классификации
      ACEA, а также прочие масла при условии наличия на упаковке нового сертификационного
      знака API - «Starburst».

Вязкость 5W/30 для холодного климата, 10W/40 (10W/30) для
      умеренного и жаркого климата.

|  | При эксплуатации автомобиля в районах с сухим климатом и высокой температурой или в других напряженных условиях должно использоваться масло для бензиновых двигателей класса SH или SJ по API с номером вязкости по 30, 40, 10W-50, 20W-40 или 20W-50 по SAE. |
