# 2.1.2 Дверные замки

## Текст

Дверные замки

Отпирание и запирание дверей снаружи

![[assets/7282c803428fbf7e.jpg]]

1. Для запирания двери снаружи с помощью
        ключа поверните ключ по направлению к задней части автомобиля. Для отпирания
        двери поверните ключ по направлению к передней части автомобиля.

2. Для открывания незапертой на замок двери оттяните вверх наружную ручку.

![[assets/d280e2937022186f.jpg]]

3. Для запирания передней двери снаружи
        без ключа отожмите назад встроенный во внутреннюю ручку двери блокировочный
        рычажок и захлопните дверь, подняв наружную ручку.

4. Для запирания двери задка снаружи без ключа поверните внутренний рычаг замка
назад и закройте дверь.

5. Перед уходом запирайте все боковые двери, а в моделях Legacy Универсал и Outback
также дверь задка.

|  | При запирании дверей снаружи без ключа старайтесь не оставлять ключи в салоне. |
| --- | --- |

Отпирание и запирание дверей изнутри

![[assets/7a17cbea55d032d1.jpg]]

1. Для запирания двери изнутри поверните
        встроенный во внутреннюю ручку двери блокировочный рычажок замка назад.
        Для отпирания двери поверните рычажок вперед.

2. В отпертом положении замка становится видна красная метка на блокировочном
рычажке, - теперь, чтобы открыть дверь достаточно потянуть на себя ручку.

3. Перед началом движения удостоверьтесь в плотности захлопывания всех дверей,
включая дверь задка (Legacy Универсал и Outback).

Дополнительная блокировка замков задних дверей (Child Lock)

1. Дополнительная блокировка предусмотрена с целью предупреждения случайного
отпирания задних дверей автомобиля в результате шалостей перевозимых на заднем
сиденье детей.

![[assets/31594464fc0485a8.jpg]]

2. Откройте дверь и переведите блокировочный
        рычажок положение LOCK (Запереть), - после захлопывания дверь сможет быть
        открыта только снаружи.
